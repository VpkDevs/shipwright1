# Shipwright Assisted Pilot Offer

## Offer

**Shipwright Deployment Rescue Pilot - $49**

Send one public GitHub repository. Shipwright analyzes the repo, proposes deployment assets, and returns a reviewable pull request. The pilot includes one founder-assisted pass so early buyers get an outcome while the self-serve flow is still earning trust.

## Buyer

Solo developers and small teams with a useful repository that is stuck before deployment.

## Outreach Message

```text
I built Shipwright to turn an undeployed GitHub repo into a reviewable deployment PR.

I am opening five assisted pilots at $49. Send one public repo and I will run the workflow with you, review the generated PR, and fix one deployment blocker.
```

## Fulfillment Checklist

- Confirm the repository is public or the buyer has authorized access.
- Run analysis and generate the PR.
- Review generated changes before asking the buyer to merge.
- Record the blocker category and time-to-PR.
- Ask for a short quote only after the buyer gets a useful result.
